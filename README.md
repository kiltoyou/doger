# Doger Messenger

Фронтенд-каркас мессенджера Doger. Стиль: **Modern Glass Neo** — тёмная тема, стекло (glassmorphism), скругления, неоновые градиенты.

## Стек
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- lucide-react (иконки)

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  components/
    Sidebar.tsx        — боковая навигация (5 вкладок)
    ChatsScreen.tsx     — список чатов + окно переписки
    LiveRoomScreen.tsx  — совместный просмотр + видеозвонок
    ProfileScreen.tsx   — карточка профиля
    SearchScreen.tsx     — поиск людей/каналов/групп
    NotificationsScreen.tsx — лента уведомлений
    GlassCard.tsx        — переиспользуемый стеклянный контейнер
  data/mock.ts          — тестовые данные (чаты, сообщения, участники)
  data/extra.ts         — тестовые данные (поиск, уведомления)
  types.ts              — общие TypeScript-типы
  App.tsx               — роутинг между экранами
  main.tsx              — точка входа
```

## Как поиграть с другом онлайн

Локальный запуск виден только тебе. Чтобы друг из другого города мог зайти и вы общались по-настоящему — нужно выложить сайт в интернет (бесплатно). Пошаговая инструкция: **[`DEPLOY.md`](./DEPLOY.md)**.

## Как запустить всё вместе (локально)

1. Подними backend (см. `backend/README.md`) — он должен слушать `http://localhost:4000`
2. В корне фронтенда скопируй `.env.example` в `.env`
3. `npm install && npm run dev`
4. Открой `http://localhost:5173` — увидишь экран входа. Если делал `npm run prisma:seed` в backend, войди как:
   - `alexey@doger.app` / `password123`
   - `anya@doger.app` / `password123`

   Или зарегистрируй нового пользователя прямо на экране входа.
